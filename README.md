# 66Archive · 女流66 网络生涯档案

**女流66（石悦）从 2010 年至今的视频、直播与相关资料索引。**

网站：**https://nvliu.wiki/**

> **最后更新：2026-09-25**  
> **当前阶段：补档 / 数字考古 / 来源复核 / 画廊整理**

66Archive 是一个持续整理中的民间资料项目，不代表女流66本人或相关平台的官方档案。

**只索引，不搬运。** 仓库和网站不保存直播、视频本体；可播放内容尽量链接回原平台、原投稿或仍可访问的录播来源。对于已经失效、仅存单一来源或暂时无法公开核验的资料，项目优先保存来源、目录、时间、文件名和调查记录，而不是为了“补满”时间线去猜。

## 当前状态

网站的主要产品功能已经基本收口：编年史、故事模式、Highlights、游戏 / 节目聚合、数据统计、画廊、协作校对、资料纠错与来源追溯都已进入日常使用阶段。

项目现在的默认目标已经从“继续扩功能”转为**把档案本身补得更完整、更可靠、更可追溯**。除明确的 bug、性能 / 兼容性 / 安全问题，或维护者明确提出的新需求外，不主动扩大产品面。

## 网站里有什么

- **编年史 / 故事模式**：按日期浏览已经确认的视频、直播和重要事件，并从完整时间线中抽出阶段性节点；
- **Highlights**：整理比较有代表性的节目、事件、梗和名场面；
- **游戏 / 节目**：把时间线重新按游戏和长期栏目聚合；
- **数据统计**：从现有档案计算直播记录、已确认时长、年度分布等，并展示当前仍然存在的资料缺口；
- **画廊**：保存与时间线相关的图片、截图、周年资料、线下活动和其他视觉记录；
- **协作校对**：编年史条目里可以直接核对游戏标签并搜索完整游戏词库；“联系我们”可以提交资料纠错，首页“直播间梗”也可以补充线索。无需注册，所有反馈都会人工复核，不会自动改写档案；
- **来源索引**：尽量保留原始页面、录播、目录、失效链接和调查记录，让资料即使暂时不能播放，也仍然可以继续追溯。

主要数据位于：

- [`data/entries/`](data/entries/)：时间线主体；
- [`data/games.yaml`](data/games.yaml)：游戏档案；
- [`data/series.yaml`](data/series.yaml)：节目 / 系列；
- [`data/tags.yaml`](data/tags.yaml)：受控内容标签；
- [`data/accounts.yaml`](data/accounts.yaml)：相关账号与来源；
- [`data/catalogs/`](data/catalogs/)：采集目录、逐条处置表和对账表；
- [`data/reports/`](data/reports/)：缺口调查、来源审计、考古报告和修正记录。

网站前端也公开在这个仓库中，欢迎查看、改进或提交 PR。生产运维配置、后台内部实现和凭据不属于这个公开仓库的内容。

## 数据与考据原则

这个项目现在更看重“为什么这样记”而不是“数字看起来是否完整”。目前统一遵守这些原则：

- **上传时间不等于直播时间。** 优酷 / A站 / B站的投稿时间只能作为上界或辅助证据，除非画面、同期帖子、房间快照或当事人自述能把直播日钉死；
- **同一天不等于同一场。** 同日多次开播会分别记录；斗鱼断线重连则尽量合并回同一场，不因为出现多个 show ID 就机械拆条目；
- **跨午夜按实际开播日归档。** 午夜后的尾段不会自动变成第二天的新直播；
- **二手节目单不能单独建条目。** 节目单、后补整理帖、后来的分P日期如果同源，只算一条证据；和画面时钟、当日快照等一手材料冲突时，以更强的一手证据为准；
- **不为完整度牺牲不确定性。** 能确认到年份就只写年份，能确认到日期但不能确认游戏就让游戏字段留空；
- **完整录像优先于短切片，但短切片仍可作为证据。** 条目允许同时挂整场、纯净版、弹幕版和片段，note 会尽量写清覆盖关系；
- **已失效来源不随便删除。** dead URL、旧 vid、分享码、文件名和上传者账号仍然是考古证据，会保留在目录或报告中；
- **涉及第三方隐私的图像不公开。** 电话、住址、快递单、好友列表等不进入公开资料；线下合照等边界材料交给人工审核。

## 目前仍然值得追的缺口

### 2015

2015 已经从“大片空白”进入“少量明确难题”阶段。当前最缺的不是再跑一轮搜索，而是新的**一手材料**：

- **05-16～06-22** 仍有 19 个只有节目单、没有独立开播证据的候选日；
- 4 月《潜伏之赤途》的具体直播日仍缺独立证据；
- 《南瓜先生》《雷曼传奇》等录像已经找到，但精确日期仍没有钉死；
- 少数早期 MC / 大周场次、第二届建筑大赛等仍缺准确直播日；
- 09-27 心灵砒霜、12-11 故宫等已知曾存在的资源仍未找回完整公开录像。

这部分如果没有新的旧截图、原硬盘 / 网盘目录、同期帖子或带日期的录像，再继续换关键词搜索的收益已经很低。

### 来源风险

来源风险已经单独做成 [`source-risk-rescue-inventory.csv`](data/catalogs/source-risk-rescue-inventory.csv)。目前最值得警惕的几类是：

- 2010–2014 的一批早期原创视频只剩她本人优酷号单一来源，其中已有视频加密或失效；
- 2015 仍有若干直播只剩 A站 / 优酷 / 单个 B站搬运中的一个来源；
- 2019–2022 仍有一批直播只有斗鱼官方回看，没有其他公开镜像。

这些风险目前先做**索引、证据与镜像线索登记**，不把“全量下载并重新托管视频”当作公开仓库职责。若未来做私人冷备份，也会与网站播放 / 分发分开处理。

### 画廊

画廊是当前正在推进的一条新主线。重点不是单纯把图片数量做大，而是补足能够说明历史变化的视觉资料：

- 2015–2021 的摄像头 / 直播环境 / 房间变化；
- 重要周年、生日、线下活动与平台时期变化；
- 大周 MC、心灵砒霜、长期栏目等有明确历史意义的代表画面；
- 老平台、旧帖子、失效页面中正在消失但仍能核验出处的视觉材料。

所有新图先进入**本地人工审核批次**，维护者确认 KEEP 后才进入 `gallery-photos.yaml` 与公开画廊。

## 目前最需要帮助的地方

如果你手里有下面这些资料，会比“再提供一个模糊日期”更有价值：

- **2015 年旧直播截图 / 录像 / 文件目录**，尤其是 5–6 月、早期 MC、《潜伏之赤途》《南瓜先生》《雷曼传奇》等；
- **旧网盘 / 硬盘文件列表**：即使分享链接已经失效，只要还能看到文件名、文件夹日期、大小或截图，就可能帮助定日；
- **早期优酷视频的备份或搬运**：2010–2014 有一批内容目前只剩单一来源；
- **仅存斗鱼回放场次的其他录像**：B站 / A站 / 网盘中同场的完整或互补录播都欢迎；
- **旧截图、周年视频、线下活动照片和画廊资料**：最好同时提供大概年份、原始出处或能帮助定位时间的信息；
- **纠错与补来源**：日期、标题、时长、游戏 / 节目标签、来源链接有误或失效，都可以直接指出。

## 怎么帮忙

现在有几种方式可以直接参与：

- 在**编年史**对应条目的展开区域里核对游戏标签；看过原片后，可以直接从完整游戏词库里搜索并提交判断；
- 在网站的**“联系我们”**页面直接提交日期、标题、时长、来源等纠错；首页**“直播间梗”**区域也可以补充梗和名场面线索；
- 也可以继续通过 GitHub 提交 **Issue / Pull Request**。

网站内提交无需注册，只会作为待复核线索；**任何反馈都需要人工核对后才会进入档案，不会自动写回 `data/**`。**

如果是补档，最好附上能够核验的信息，例如：

- 原视频 / 录播链接；
- BV / AV / AcFun / 优酷 / 斗鱼回放 ID；
- 原始标题、上传时间、直播日期；
- 截图、水印、评论区时间线索；
- 旧网盘、硬盘目录或直播日历。

证据不足的内容不会为了补齐时间线而强行写入；能够确认多少，就记录多少。
