# Chronicle-66 · 女流66 网络生涯编年史

女流66（石悦）自 2010 年至今网络生涯的作品索引网站：优酷解说视频、斗鱼与抖音直播场次，按时间轴呈现，带 hover 预览。

**只索引，不搬运**——服务器上不存放任何视频文件，所有链接指向原平台、原 UP 主。数据以 `confidence` 分级标注确定性，未核实的内容一律留空或标 `low`。

## 生涯内容统计（2026-08-11 数据快照）

总条目 **2826** 条，覆盖 **2010-05-08 ~ 2026-08-10**，横跨视频 / 直播两个形态、五个平台（优酷 / 哔哩哔哩 / YouTube / 斗鱼 / 抖音）。

|---|---|---|---|---|

| ② 斗鱼时期 | 2015-02 ~ 2023-12 | 斗鱼直播 | 2055 | 直播间 156277；固定栏目《心灵砒霜》（254 期）等 |

- **系列 / 栏目**：12 个（视频时代 7 个解说系列 + 斗鱼时期 5 个固定栏目），详见 [`data/series.yaml`](data/series.yaml)

> 说明：视频时期条目中 51 条原优酷页面已失效（仅目录快照可证实），26 条仍可访问；斗鱼/抖音条目为直播场次元数据，来源为 A 站录播频道与 B 站搬运回放。

## 站点功能

- **时间轴**：竖条高度 = 直播真实时长，条内色带 = 当场所玩游戏；hover 预览详情
- **系列展示**：按系列 / 栏目高亮与筛选（`series.yaml`）
- **数据分级**：每条目标注 `confidence`（high / medium / low），来源链接区分 original / replay / clip / reupload

## 跑起来

```bash
npm install
npm run dev
```

其他命令：

```bash
npm run validate     # 数据校验闸门，任何数据 PR 都要先过它
npm run build        # 校验 + 静态导出到 out/
npx tsx scripts/gen-demo.ts   # 重新生成演示数据
```

## 数据模型

```
data/
├─ accounts.yaml     # 平台账号盘点（官方 + 搬运/补档）
├─ games.yaml        # 游戏库（仅人工添加）
├─ series.yaml       # 系列 / 栏目
├─ entries/          # ★ 真实条目，按月份分文件（2010-05 ~ 2026-08）
├─ catalogs/         # 原始枚举目录（采集来源，供复查）
└─ _demo/            # 演示数据，真实条目就位后失效
```

数据格式的唯一权威定义在 [src/lib/schema.ts](src/lib/schema.ts)。`npm run validate` 校验 Schema、id 唯一性与链接格式。

## 硬约束

1. 不存放视频文件，只存元数据与外链
2. 不编造数据：没核实的一律留空或标 `confidence: low`
3. Schema 只由架构角色修改；数据由采集角色收集，`games.yaml` 仅人工添加

本项目由多个 Agent 分工完成（架构/前端、数据采集、工具/自动化、审校）。分工契约与协作文档存放于本地 `.claude/docs/`（不纳入本仓库），起手规则见 [AGENTS.md](AGENTS.md)。
