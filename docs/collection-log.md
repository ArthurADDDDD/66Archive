# 收录日志

「数据」页底部左栏记录网站主要功能变化，右栏记录新收录的视频、录播和画廊素材。

右栏通过公开只读接口 `/api/content/collection-log` 自动更新。每条包含标题、类型、站内链接、内容发生日期（有明确日期时）以及首次收录确认时间。新增内容正式进入当前公开档案后出现；照片在确认公开后出现。准备中的内容、失败的收录和隐藏内容不显示。

- 时间戳按北京时间显示，精确到秒；对应入库确认，不是直播时间、视频上传时间或机器开始抓取的时间。
- 每个新增条目单独记一条。重复收录和修改旧条目不会刷新首次时间。
- 首次读取 30 条，滚到框底或点击「查看更早收录」继续读取。页面浏览到日志且停留在框顶部时，每分钟检查一次更新。
- 历史收录摘要保留已核对的日期；没有可靠的时分秒记录时，不补造精确时间。
- 接口不可用时保留已加载内容，并提供重试及历史摘要。

响应格式：`{ items, nextCursor }`。`items` 每项只含 `id`、`type`（`live` / `video` / `gallery`）、`title`、`contentDate`（可空）、`recordedAt`（ISO 时间戳）与 `href`（站内链接）。将不透明的 `nextCursor` 传回 `?cursor=…` 可继续读取；空游标代表末页。
