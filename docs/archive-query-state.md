# 录播室地址状态恢复

录播室的年份、月份、关键词、平台、类型、游戏和可播放筛选保存在 URL 中。
`src/lib/archive-query.ts` 统一解析与序列化，日期导航链接与本地筛选使用同一套规则。

此前只在组件首次挂载时恢复查询参数；客户端保留组件而改变同页查询参数时，
地址栏和结果可能不一致。现在通过路由的查询参数订阅处理地址变化，包括浏览器
前进后退。恢复空查询串也会清除旧筛选并回到最新年份，不再因为查询串为空而忽略。

本地输入仍使用 replaceState，不会每输入一个字就增加历史记录。通过已应用参数
标记避免把本地刚完成的筛选重放一次。外部地址变化时清除旧结果的展开项、月内标签
和筛选弹层；日期链接仍保留平台等筛选，但退出全库关键词搜索。

自检命令：`npm run test:archive-query`、`npx tsc --noEmit`、
`CONTENT_BAKE_ORIGIN=off npm run build`。自动化用例覆盖中文与特殊字符往返、
空参数、无效日期、合法月份及未知参数忽略。浏览器另外检查实际路由订阅及历史导航。

本轮在本地静态产物中确认：同页切换“传送门”与“星露谷”时结果同步变化；
后退恢复旧查询，再后退到空查询会清空搜索，前进可恢复。移动视口搜索弹层填写后
焦点保留、历史记录数量不增加，全程只有一次档案载荷请求。未验证真实手机与其他浏览器。
