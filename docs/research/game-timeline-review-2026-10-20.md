## 1. 口径与证据等级

- 统计口径仍以 [`docs/game-time.md`](../game-time.md) 为唯一依据。
- 本轮新增/修改的边界全部来自对基准录像的**定向抽帧**（B 站分 P 或 A 站分 P），证据等级为 `thumbnails`；没有新增 `human_watch`、`scanned`，也没有把任何 unknown 升为已核实。
- 抽帧只用于确认「画面里是什么」和大致边界；没有连续观看整段录像的位置一律保留近似精度（`approx`）或分 P 精度（`part`）。
- 旧 `segments` 仍只作为线索。它们常使用整场累计时间，边界比新时间轴粗，不能直接覆盖分 P 内时间。

## 7. 前端语义

- 游戏：`已核实游戏环节` / `关联录像，内部或边界尚未全部核实`（原有语义）。
- unknown：标题显示「未归类片段（聊天）」等，说明文字为「未细分到具体游戏，仍可能属于游戏环节」；**不再**显示「不计入游戏时长」。
- break：统一标题为「独立环节」（有具体活动名称时优先显示活动名），说明文字为「不计入游戏时长」。
- 录像页进度条的 unknown/break 名称同步修正。
- 新增两个站点文案 ID：`entry-detail-game-kind-independent`、`entry-detail-game-unknown-note`。按现有 Site Copy 机制，新 ID 会在下一次内容同步时以加性方式被后台采纳；没有改动私仓。

## 8. 自动化护栏

`npm run test:game-timeline-gaps` 现在会：

1. 对 `coverage: complete` 检查条目游戏是否全部有环节（失败）。
2. 对 partial/unknown 缺口要求逐条登记在 `REVIEWED_GAPS`；新缺口失败，已修复项会提示从登记表移除。
3. 用旧 `segments` 的游戏标签交叉核对长 unknown；新命中失败，已复核例外登记在 `REVIEWED_CROSS_CHECKS`。
4. 要求所有 ≥30 分钟 unknown 登记在 `REVIEWED_LONG_UNKNOWNS`。
5. 核对本轮关键游戏段的起点、终点、关联秒数和已核实秒数（带容差）。
6. 核对条目不再含已退役标签（`meituan`、特定场次的 `overwatch` / `monopoly-plus` / `sos-fomt`）。
7. 核对 Reigns 三作 ID 不混用。
8. 核对每个时间轴的环节总时长 = 基准录像总时长。
9. 核对已核实总秒数仍为 186,628；unknown 不得带 `human_watch` / `scanned`。
