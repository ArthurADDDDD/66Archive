详见 [早期报告](early.md)、[中期报告](middle.md)、[近期报告](recent.md) 及对应 CSV。来源字段 `alive` 是基线记录，不等于本次在线复核结论。访问失败、验证码、动态壳和反爬都不能作为资源不存在的证据。

## 上次显示规则的问题

[隐藏规则复核](hidden-footage.md) 逐项重现了 122 个条目与游戏的组合：91 个 `missing`、26 个 `unverified`、5 个 `partial`。三类在界面上全部显示为“录像缺失”，措辞超出了证据支持的范围。

- 没有确认来源，只能说暂未找到；来源访问受阻或未核实，只能说待核实。
- 没有游戏章节定位，不代表相关影像不存在。已知互补源不得因尚未定位而被描述为缺失。
- 切片和精剪不能占据完整录播的播放位置，但也不能被描述为没有任何影像。
- 游戏页隔离无关来源时，应保留通往完整场次档案的入口。

上述行为修正不构成对来源内容、直播日期或完整性的批量确认。
