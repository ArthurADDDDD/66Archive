# 未引用 B 站分段：公开导入沿革与匹配依据

本报告只读检查公开 Git 历史、基线 `d019ca1b`、公开导入总结和既有本地来源目录；不访问网络、不查私仓、不改应用代码或正式数据。范围限于两个代表日期：2022-02-25 和 2023-10-30。

## 结论先行

公开记录能证明，2026-08-31 的 B 站补源批次按直播日期、标题相似度和时长筛选来源，并在 168 个条目中补入 B 站投稿；该提交也把更大的 B 站投稿目录一并登记。在下面两个代表日期的提交结果中，各自只关联一个 B 站 BV（2022-02-25 的 P3、2023-10-30 的 P2），而同目录另有同日、同系列标题标注的 P1/P2/P4 或 P1/P3 候选。

但公开仓库没有保留该批次的导入脚本、逐候选选择日志或规则，能证明为何每场最终只登记该一个 BV。只能确认这两个样例的提交结果各只关联一条 B 站来源；不能据此概括所有条目的导入规则。“导入程序有意只补一个分段”或“其它标题为 P 的投稿一定是同一场的连续分段”目前都只是推断，不能定论。上传账号是否遗漏或漏存也不能由当前档案缺链接推出。

## 可直接确认的导入流程证据

- 公开报告 [`task-034-bilibili-source-priority.md`](../../../data/reports/task-034-bilibili-source-priority.md) §§2–4 记载：先枚举 B 站“女流录像小屋”空间目录；目录 `live_date` 从标题解析，`pubdate` 是投稿日；对原先只有 AcFun 来源的条目，按 `live_date == entry.date` 找候选，再按标题相似度与时长吻合度筛选。报告统计 168 条补入，156 条按阈值通过、17 条进入人工复核（12 采纳、5 否决），另有 43 条当天无可用稿件。
- 同一报告明确承认两平台拆分粒度可不同：AcFun可能按P拆开，B站可能是一整场，反过来也可能发生。因此报告里的时长吻合不是固定的“一页对应一场”规则，更没有声明每个P都自动逐项补齐。
- 公开提交 [`db23a6df`](https://github.com/ArthurADDDDD/66Archive/commit/db23a6df156cfdb8d396be93f259f226c42613ff) 添加完整 B 站目录。对本报告的两个目标日期，提交差异分别把一个 BV 来源写入当前条目；差异没有记录同日未选候选的排除理由，也没有可复算的逐分段导入器。
- 本轮找到的 [`scan_unlinked_bili_parts.py`](scan_unlinked_bili_parts.py) 是后来为只读候选筛选编写的脚本，不是历史导入器。它按精确直播日期、去掉显式分段标记后的精确标题、候选标题是否标P来排序；脚本注释与输出都把这些称为候选，而不裁决来源是否同场、连续、可播或完整。

## 代表案例一：2022-02-25《艾尔登法环》

在 `d019ca1b` 基线，条目 `2022-02-25-live-01` 引用 B 站 [BV1oY411G7nx](https://www.bilibili.com/video/BV1oY411G7nx)，目录标题是“女流-P3-2022.2.25-艾尔登法环”。同条也有 AcFun 来源；现有条目备注记载 AcFun 将该场拆成四个回放段，条目总时长为 678 分钟。公开目录当天另列 B 站 P1 [BV1da41187va](https://www.bilibili.com/video/BV1da41187va/)、P2 [BV1Nu411Q79H](https://www.bilibili.com/video/BV1Nu411Q79H/) 与 P4 [BV1zm4y1R75f](https://www.bilibili.com/video/BV1zm4y1R75f/)，目录时长约各 169 分钟；这些链接没有进入该条目 sources。P3 已链接，三个其它页被本地脚本列作既有 13 场候选，不作为新发现。

`db23a6df` 的 2022-02 条目差异显示补入 P3 BV1oY411G7nx；`task-034` 总结展示该次 B 站补源如何按条目日期与匹配分数选定 BV。可确认“提交结果只关联P3”，不能从提交差异判断是否曾比较过 P1/P2/P4。候选页标题分段号、同日、同游戏和相近时长使它们值得核对，但候选本身不证明同一直播或连续的四个部分。

已有播放器补查 [`unlinked-candidates-player-followup.md`](unlinked-candidates-player-followup.md) 对 P1 在约 300 秒和 600 秒的样本只取得黑底/未就绪，保留内容判读缺口；P2 约 601 秒与 P4 约 301 秒取得艾尔登法环画面。它们说明候选页有可辨认内容的局部样本，不证明四页连续、不重叠，也不构成整场覆盖认证。

## 代表案例二：2023-10-30《心灵杀手2》

在 `d019ca1b` 基线，条目 `2023-10-30-live-01` 只引用 B 站 [BV1zG411C7gD](https://www.bilibili.com/video/BV1zG411C7gD/)，其目录标题自称 P2，时长 180:54。目录另有同日同系列 P1 [BV16Q4y1H78a](https://www.bilibili.com/video/BV16Q4y1H78a/)（180:53）和 P3 [BV11C4y1n7Mu](https://www.bilibili.com/video/BV11C4y1n7Mu/)（180:54）；两者未链接。三项均在 B 站录像小屋目录，投稿账号的现有页面元数据标为同一账号 UID 29418340，故不能把三条投稿标题当成三个独立日期来源。

`db23a6df` 差异显示为条目添加的是 BV1zG411C7gD（P2），不是P1/P3。后来公开目录对照与 [`late-2023-unlinked-source-followup.md`](late-2023-unlinked-source-followup.md) 为另外两页提供了已存在的 API 与局部播放器观察：P1 尾部约 10846 秒与已挂 P2 开头约 3.5 秒显示同一案件证据板事件，支持 P1→P2 的局部接续；P3 开头约 2.8 秒显示相同游戏场景和递增状态，和 P2 尾部相容，但尚未证明无间隔。P2 尾部跳转两次未取得媒体画面，因此 P2→P3 接缝仍未核实。页面自称 P1/P2/P3 与同账号、同日标题构成关联线索，实际连续覆盖仍须逐段确认。

此案说明目录中确有条目未引用的同日P1/P3页面，不能笼统说“没有资源”；它不能证明早期导入依据、上传者意图，或自动导入漏掉这些页的具体原因。
