# AcFun 未挂目录投稿：详情页 metadata 覆盖与异常线索

日期：2026-10-24。固定输入是 [336 条未挂目录 ID](acfun-directory-unlinked.csv)，不扩展其它账号或目录。将此前成功页面 metadata 去重后复用 36 条，本轮对剩余 300 个 ID 各发出一次普通 AcFun 公开详情页 GET，约每秒一次；300/300 均成功，未遇到 blocked/error，也未重试。详情行与覆盖状态见 [JSONL](acfun-unlinked-detail-audit.jsonl) 和 [CSV](acfun-unlinked-detail-audit.csv)；逐批请求工具为 [fetch_acfun_unlinked_detail_batch.py](fetch_acfun_unlinked_detail_batch.py)。

## 覆盖范围和字段

最终表对 336/336 个目录 ID 都保留一行：31 个此前候选详情页 + 5 个 Nov 12 页面从现有 JSON 复用，共 36 个 `reused_local:*`；外接盘 journal 在此固定全集没有额外可复用的成功行；300 个新页面标 `metadata_ok` / `new_public_page_get`。未成功页会被记录为 blocked/error/not_attempted，而非“来源不存在”；本轮无此类结果。336 个页面都公开返回 UID `4397992`。网页页内 videoList 条目总数为 1,196，没有空 videoList。每行保留目录标题与目录上传日期作原始上下文、详情页标题、公开 UID、所有 videoList 内页序号/标题/秒数、状态和获取来源。

只读取普通公开 HTML 中选定的页面 metadata。没有请求或保存媒体流、token 或原始 HTML；不保留投稿时间，也不从它推断直播日期。每条 metadata 都不是播放器/画面核验，不能证明可播放、内容范围、分段连续或整场完整。上传者目录只是单个账号的一份历史快照，不是全站 AcFun 清单；这批 ID 原先“未挂档案”也不代表 336 个遗漏或 336 场独立直播。

## 本地异常排序

以下是按页标题和 videoList 字符串排序的机器线索，均不判错误、缺失或内容范围：

| 机械线索 | 数量 | 备注 |
|---|---:|---|
| videoList 为空 / duration 为 0 | 0 / 0 | 本批 metadata 未见这两种状态 |
| 任一内页 ≤60 秒 | 1 | [ac3017346](https://www.acfun.cn/v/ac3017346) 唯一内页 metadata 为 11 秒；短片或片段可能合理，需内容证据才可判定范围 |
| 顶层与内页标题日期不一致 | 10 | 日期只按标题字符串解析，既可能是跨午夜、标题误字，也可能是合辑/跨场；不自动纠正 |
| 分 P 标题序号非单调 | 3 | 依 videoList 数组序检测：`2,3,4,1`、`2,3,…,13,1`、`6,7,6`；导航仍应按数组序，不能依标题重排 |
| 同页出现重复 P 标签 | 5 | 两页是相同标题范围重复（P2 重复），三页是不同标题/节目间重复编号；后者可能是编号重启，需避免误报 |
| 多个书名号作品名 | 3 | 这些是已有 Nov 12 页面 metadata，故不重复列入新增建议 |

日期冲突中的三条 `2021.11.31` 顶层标题和 Nov 12 页面已在之前任务优先复核，此处虽计入全量异常扫描，但不再作新检查建议。对全量异常分类、P号序列、日期集合及最短时长字段，可直接筛选 [CSV](acfun-unlinked-detail-audit.csv)。分 P 号非单调仅意味着标题号与数组顺序不一致；AcFun 播放器页序仍以 videoList 数组序为准。

## 限制

报告完整覆盖目录 CSV 的 336 个不同 ID 及其当前可读取的公开详情 metadata；它没有覆盖未列在该 CSV 的其它 AcFun 投稿。未播放任何本轮300个新页面，没有确认标题是否与画面相符、能否seek到尾、各页是否相邻或来源是否为剪辑。没有正式数据、主观察 JSON 或既有 CSV 被修改。本轮使用的公开 UID 只记录在审计产物中；没有作账号可信度评分。
