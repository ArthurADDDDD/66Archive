# 2016-01-24 纪念录像来源范围本地复核

本报告依据当前仓库档案、既有目录/审阅记录、代码和 Git 公开历史整理。未联网；B 站播放器的三点观察由根 Agent 提供，本报告不声称由本 Agent 亲自检查。未改 `data/`、代码或主观察 JSON。

**结论：当前正式档案没有把 `BV1Rx411S7Ta` 排除在 Minecraft 条目的来源范围外。** 条目 `2016-01-24-live-01` 目前登记 `games: [minecraft]`，B 站 source index 0 和两条 A 站来源均为 `kind: replay`、`status: alive`。没有 `missing_footage`，也没有该条目的游戏时间轴。B 站来源没有单独的游戏范围、标签或其他排除字段。

## 已有 B 站页面证据

当前 B 站来源为 [BV1Rx411S7Ta](https://www.bilibili.com/video/BV1Rx411S7Ta)。本地缓存记录其投稿标题为“【女流】女流直播一周年纪念 2016-01-24 超清”、投稿者 UID 26781849、单内部页，metadata 时长 5,831 秒。根 Agent 报告正常播放器实际时长为 5,830.6 秒，并在 `t=600`、`t=3000`、`t=5700` 秒看到的都是旧视频/聊天画面，没有看到 Minecraft。

三处样本支持“这三个抽样点没有 Minecraft 画面”，并使这条来源的游戏范围值得进一步核实；它们不能证明 97 分钟内完全没有 Minecraft，也不能推出该来源整条都不属于同场内容。页面 metadata 时长与实播时长仅约 0.4 秒差异。

## 97 分钟注释与当前 BV 的关联疑点

条目现有备注写道：将条目时长从 97 分钟增至 236 分钟，是按两条 A 站录像的 126+110 分钟合计；“B站「影忆丶Yi」《女流之心灵砒霜-2016补档》对应分P 的 97 分钟是剪辑版，不代表当日直播全长”。这段备注把旧来源称作剪辑版，却没有在文字中给出 BV 号。

仓库 Git 历史显示，条目最初曾同时列出 B 站 [BV1ZN411o7VN?p=4](https://www.bilibili.com/video/BV1ZN411o7VN?p=4)（“影忆丶Yi”《女流之心灵砒霜-2016补档》）与 [BV1Rx411S7Ta](https://www.bilibili.com/video/BV1Rx411S7Ta)。后续修订移除了前一链接，只保留 `BV1Rx411S7Ta`，并保留了关于“影忆”97 分钟剪辑版的备注。当前缓存却把 `BV1Rx411S7Ta` 识别为不同投稿者 UID 26781849、不同标题的单页投稿。因而，备注中“97 分钟剪辑版”究竟只指已移除的 `BV1ZN411o7VN?p=4`，还是也描述现在仍挂载的 `BV1Rx411S7Ta`，现有文字和旧历史不足以裁定。两条时长相近不能单独证明是同一版本或同一内容。

## 前台如何呈现来源范围

- `data/game-timelines.yaml` 没有 `2016-01-24-live-01` 的时间轴条目。因此没有以基准来源、分 P 与 spans 将 Minecraft 环节和聊天/其他节目环节分开，也没有由时间轴提供的逐来源游戏边界。
- `src/lib/narrative.ts` 的 `getGameProfile` 按条目的 `games` 字段匹配 Minecraft 场次，不按同一条目的来源各自判断游戏。`src/lib/data.ts` 的 `toTimelineEntries` 会把条目组内所有来源展平投影，不依据 `kind`、标题或来源顺序过滤某一来源。
- `EntryWatch` 默认选中首个 `alive` 来源；本条来源顺序中 B 站链接在最前。条目页来源选择器会因此默认选中这条 B 站视频。播放器来源本身没有 `game_scope` 一类正式字段。

因此，当前档案和前台都没有显式排除该 B 站投稿的 Minecraft 范围；Minecraft 条目所显示的是场次级关联，而非对 B 站每一帧内容的确认。`duration_min: 236` 也属于场次级时长，不能据此认为任何一条来源各自都覆盖 236 分钟。

## 给根 Agent 的裁定点

现有证据组合是：A 站目录已有“MC 活动”和“读信/水友互动”的分段内容依据；当前 B 站页三个播放器点均为旧视频/聊天；但同一 B 站链接在正式条目中仍是默认首个存活来源，且条目没有来源级范围排除。最关键的未决问题不是“236 分钟是否全是 Minecraft”，而是现有备注中的 97 分钟剪辑判断能否可靠套用到当前 `BV1Rx411S7Ta`，以及这条来源的哪些实际范围与本场 A 站内容相连。没有逐页内容对齐之前，不应据三点样本排除整条来源、宣布全片无游戏，或将其计入已核实的 Minecraft 游戏环节。

## 后续补证：影忆旧 BV 的三处页面观察

后续对历史上曾列出的 [BV1ZN411o7VN?p=4](https://www.bilibili.com/video/BV1ZN411o7VN/?p=4) 取得了独立页面与播放器样本：公开 UID 15800276，14 个内页；P4 video ID 340014999，metadata 时长 5830 秒。P4 的 600、3000、5800 秒三点依次为旧来信节目、灰底文字互动、论坛帖子列表，分别与当前 B 站 BV1Rx411S7Ta 及 A 站互动稿 ac2487950 的既有相近时点局部相符。详见[影忆旧稿 P4 补充](jan24-2016-yingyi-removed-source-followup.md)。

这让历史备注中的“影忆”97 分钟关联更有根据地指向曾列入条目的旧 BV1ZN411o7VN，而当前正式首源仍是不同投稿 BV1Rx411S7Ta。它支持收窄备注的指代对象，但不证明具体剪辑操作、旧稿全片与当前来源等价、旧 P4 全程没有 Minecraft、原始母场日期或完整性。旧链接当前可访问并可播放，不应描述成死链。前文“剪辑备注归属未决”应按这项新证据更新；当前档案是否需修改仍须独立审阅，本次没有改动 `data/` 或主观察 JSON。
