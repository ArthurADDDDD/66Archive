# Douyu / Sohu 页面 metadata 与基线档案对照（2026-10-23）

本报告只对已缓存的公开页面 metadata 与基线 `34b35960` 档案字段作本地对照；没有网络 GET、播放、下载或人工画面核对。范围为 326 条 Douyu、5 条 Sohu 来源引用，共 331 行，细节见 [`other-host-local-review.csv`](other-host-local-review.csv)。

页面时长是平台 VOD 页面提供的媒体长度；`archive_duration_min` 是档案标注的直播/节目时长。它们不是同一字段，也不能据差值单独认定录像缺失。CSV 中的 Douyu 汇总仅把该 entry 已登记的所有 Douyu 页面时长相加；其他来源的分 P 时长也仅作对照，可能重叠，列名注明未去重。

## 对照结果

- Douyu：326 条。每条都有具体视频标题和页面时长；只有 1 个 source 声明账号 ID `douyu-official`（档案账户显示名“女流66”），其余 325 条未声明 source.account。已抓取字段不含页面 uploader，因此无法进行逐源账号归属核验；标题出现“女流66”也不等于验证了 uploader。
- Sohu：5 条。页面 metadata 标题均具体可辨；本轮没有提取到页面时长或结构化发布时间。其标题出现“mc六则天”或“女流”字样，但没有可核的 uploader metadata。
- 6 条 Douyu 页面标题所带日期与档案 `entry.date` 不同；它们均显示为次日，可能是跨午夜场次，也可能是日期归档差异。此项是人工复核候选，不是确认错误。
- 按 entry 聚合后，86 个有 Douyu 时长的 entry 的页面时长总和低于档案时长 70%，其中 16 个低于 30%。这仅提示可能是部分回看/页数未全登记；CSV 同时列出其他已登记来源与其 part_details 时长，不能把这个比例直接判作缺失。

## 优先复核候选

- `2017-08-01-live-01`：唯一 Douyu 来源 metadata 标题为“【直播时刻】…”且页面时长为 182 秒；档案直播时长为 240 分钟，source.kind 当前为 `replay`。标题明确指向“直播时刻”短内容，属于高风险的来源类型/覆盖候选；档案还登记了 B 站、A 站及优酷来源，但本轮未核实这些来源内容，不能据此确认整条目缺录或误标。
- 次日标题日期候选见 CSV `title_derived_date` 与 `review_flags`：2019-08-10、2021-04-29、2022-11-16、2022-12-31 等记录。标题/来源日期可能反映凌晨场或标题编辑时间；没有进一步证据时不改档案日期。
- 低于 30% 的其余候选中，多个 entry 有 B 站 part_details 合计接近档案时长，说明 Douyu 单页短于整场并不必然代表站点缺录；例如 CSV 的 `some_alternate_part_details_cover_75pct_archive` 可筛出这些对照。其余仍需来源级人工核验。

## 核验边界

- 本地比较没有验证页面当前是否可播放，未看画面，也没有逐条核对账号 uploader。
- 未发现能够仅凭本轮 metadata 确认的日期归档错误或录像内容不对应；1 条高风险短内容候选和 6 条标题日期差异仍待复核。
- `page_duration_seconds` 不能替代档案时长或实际直播时长；未据此写入或修改正式 data。
