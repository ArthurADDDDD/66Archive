## 优先核对项

1. `2015-07-06-live-01`：现有唯一回放是 3:18 Besiege 切片，Minecraft 标签来自同期线索推断，不能把该切片当成 MC 录像。直播日归属本身也有推断成分。
2. `2015-01-27-live-01` 的 3D World 标签：既有回放已识别到新超级马里奥兄弟U与 I Wanna，尚无支持 3D World 的画面；待人工判断标签。
3. `2016-02-20-live-01` 的 Rusty Lake、`2017-02-17-live-01` 的 Kalimba：现有基准缺画面，但另有文字记录，不能直接删除标签。
4. `2016-03-09-live-01` 与 `2019-07-04-live-01`：档案已明确登记缺少的内容环节，详情见早期报告。
5. `2016-12-15-live-01`、`2017-01-14-live-01`：来源为空、备注称未找到回放，却没有统一状态标记；只是字段一致性疑点，本轮未补写。

其他非官方来源不能因账号角色或身份置信度被批量判错。已有互补录像的场次应先看互补来源；`unknown` 不能算作已证实缺失。全部结论均须区分本轮页面抽查、既有复核与仍未证实的推断。

## 复算与边界

在仓库根目录执行：

```bash
node --import tsx docs/research/source-review-inventory.ts docs/research/source-review-2026-10-22
```

脚本不发网络请求、不下载媒体、不修改 `data/**`。统计按原始条目计数；同场合并组仅用于查找时间轴与关联游戏。标记存在重叠，不能相加；来源账号未绑定表示归属登记未知；账号身份置信度不表示投稿准确率。来源状态是现有档案记录，不是这次重新检测的存活状态。

`games_absent_from_basis` 只比较已存在的时间轴与同场游戏集合，不声称其他没有时间轴的场次没有游戏误标。全库只有 135 条时间轴，故这一检查对大部分场次没有内容覆盖判断。

本轮没有媒体下载或大型临时缓存，仅写入文本报告与清单。进一步观看或抽帧须按用户要求把下载与媒体临时文件放在外接存储；不要让下载器默认写入本机。
