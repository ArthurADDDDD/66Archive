# 66Archive 项目状态

> 最后更新：2026-09-02  
> 当前阶段：**补档 / 考据 / 来源复核 / 数据质量维护**

66Archive 的主要产品功能已经基本收口。时间线、故事模式、Highlights、游戏 / 节目聚合、数据统计、画廊、协作校对、资料纠错与来源追溯等核心能力均已进入日常使用阶段。

当前项目的默认目标已经从“继续扩功能”转为“把档案本身做得更完整、更可靠、更可追溯”。除明确的 bug、性能 / 兼容性 / 可访问性 / 安全问题，或维护者明确提出的新需求外，不主动增加页面、字段或复杂交互。

## 当前优先级

1. **补档**：继续寻找早期直播录像、失效视频的备份、旧网盘 / 硬盘目录、逐日开播记录和可核验的重传来源。
2. **考据**：对日期、标题、时长、直播 / 预录属性、事件时间线做交叉核验，不用推测填空。
3. **补来源**：优先给已有条目补回仍可访问的原始页面、完整录像、分 P、镜像和历史目录证据。
4. **数据质量**：继续修正游戏 / 节目 / 标签归类、重复条目、时长和来源优先级，让搜索、聚合与统计保持可信。
5. **视觉资料**：继续补周年视频、粉丝图、旧截图等画廊资料，并尽量保留时间和出处。

## 功能开发口径

“功能基本完成”不等于仓库冻结。以下工作仍然正常进行：

- 修 bug 与回归问题；
- 性能、缓存、移动端、兼容性和可访问性优化；
- 安全与稳定性修复；
- 为补档 / 审校确有必要的小型工具改进；
- 维护者明确提出的新功能。

但默认不再因为“技术上能做”就扩充产品面。新增功能应先说明它解决了哪一个真实的档案维护或浏览问题。
