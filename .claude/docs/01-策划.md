## 一、一句话定义

一个**不存放视频、只索引视频**的编年史网站：把 2010 年至今散落在优酷 / 哔哩哔哩 / YouTube / 斗鱼 / 抖音 的每一支视频、每一场直播，按时间轴串起来，并回答一个核心问题——**「他那天播了什么游戏 / 做了什么内容？」**

暂定项目代号：`chronicle-66`。站名候选：《六六编年史》《66 Archive》《一直播到现在》。

## 二、为什么做

现状的痛点：

- 资源是公开的，但**碎在五个平台**，且早期优酷视频、斗鱼时期录播多为热心网友转存，散落在各个 UP 主手里。
- 平台自身的「投稿列表」只能按时间倒序翻页，**没有跨平台的统一视图**，更没有「这场直播打的是哪个游戏、从第几分钟开始」这一层信息。
- 老内容正在自然消亡：优酷老号、失效外链、被删除的录播。**再不整理就只剩记忆。**

所以这个站的价值不在「能看视频」，而在：**索引、定位、考古、统计**。

## 三、三条不可动摇的原则

1. **不搬运。** 服务器上永远没有一个视频文件。所有播放行为都跳转回原平台/原 UP 主，把播放量还给内容源。
2. **元数据开放。** 所有条目数据以纯文本（YAML/JSON）存在仓库里，任何人可以 Fork、可以 PR、可以整包下载。站点挂了，数据还在。
3. **可考证。** 每条记录都带来源字段（谁录的、从哪来、录入人、置信度）。拿不准的信息标 `uncertain`，绝不用猜测填充历史。

## 四、目标用户与典型场景

| 用户 | 场景 | 对应功能 |
|---|---|---|
| 老粉考古 | 「那年他打《XX》那几场，我想重看」 | 游戏聚合页 + 时间范围筛选 |
| 新粉入坑 | 「他这十几年都干了啥？」 | 主时间线 + 时期导览 |
| 切片/二创作者 | 「我要找某场直播的原始录播源」 | 场次详情页的多源列表 + 分段时间点 |
| 数据爱好者 | 「他哪年产出最多？平台是怎么迁的？」 | 统计页 |
| 补录志愿者 | 「我手上有 2013 年的优酷备份」 | 贡献入口 |

## 五、内容范围

分两个时期（站点的一级叙事结构）：

**视频时期（约 2010 → 直播化之前）**
- 优酷：最早的投稿，很多已失效或仅存网友转存 —— 优先级最高，因为最容易永久丢失
- 哔哩哔哩：老视频、后期的精剪/合集
- YouTube：待确认是否有官方频道及镜像

**直播时期（→ 至今）**
- 斗鱼：早期直播，录播主要靠网友转存
- 哔哩哔哩：主体部分，官方回放 + 录播 UP 主
- 抖音：近期直播

> ⚠️ 各平台的**确切起止年份、账号 ID、是否官方号**目前均为待考证项。建站第一步不是写代码，是先做一次**平台账号盘点表**（见 `docs/03-数据源盘点.md`，待填）。文档里不写没核实过的年份。

## 六、路线图

### 阶段一 · MVP（目标：2～3 周内可上线）
- 数据 Schema 定稿 + 校验管线
- 主时间线 + hover 预览 + 筛选 + 搜索
- 场次/视频详情页
- 人工录入一批种子数据（建议先做完整的 2 个年份 + 一个完整的游戏系列，用来验证 Schema 是否够用）
- 静态部署上线

### 阶段二 · 众包补录（长期）
- 贡献指引 + 一键生成 GitHub Issue 的表单页
- 「缺口地图」：可视化展示哪些月份/哪些系列还是空白，引导志愿者认领
- 链接存活性检查 + 失效标记

### 阶段三 · 自动化（远期目标）
- B 站 / 抖音 / 斗鱼 的公开接口定时抓取新内容，自动开 PR，人工 merge
- 录播 UP 主的关注列表监控（新录播自动挂到对应场次下）
- 从直播标题、弹幕高能点、录播分 P 名自动推断游戏标签，人工复核

## 七、风险与对策

| 风险 | 对策 |
|---|---|
| 平台封面图防盗链（B 站尤其） | 走图片代理 + 缓存，只用缩略图尺寸；提供全局关闭开关 |
| 外链大规模失效 | 定期存活检查；一个场次支持挂多个备用源；失效条目保留元数据并标记 |
| 版权/肖像争议 | 全站只有元数据与外链；提供显著的下架申诉入口；不放完整封面大图、不做二次分发 |
| 数据录入量大、人力不足 | Schema 允许字段留空、允许分批完善；先保证「时间 + 标题 + 链接」三件套，游戏标签后补 |
| 早期历史无法考证 | `confidence: high/medium/low` 字段 + 前端明确标注「待考证」，不做假装确定的叙述 |

## 八、成功标准

- 能在 10 秒内找到「某年某月他播的某个游戏」
- 覆盖率看板：视频期条目数 / 直播期场次数，逐月无空洞
- 有 ≥ 5 位站外志愿者提交过数据 PR
