## 8. 隐线 / 冷知识处理（用户定调：附词条下方，不抢戏）

用户：「隐线只负责报时间。」做法：作为**所属词条底部的一行弱化脚注**，不可点击（无 URL），不进时间轴主视觉、不占独立卡片。

### 视觉规格

- 位置：紧贴所属词条正文下方，与正文同左缩进，非独立卡片
- 样式：小字号（~12px）、弱化前景色（~45%）、等宽小标签 `GAME WORLD`
- 格式：`GAME WORLD · <相对时间> · <一句事实>`；无相对时间则只给绝对日期
- 交互：纯文本，hover 无态，不跳转

示意（科目二词条）：

```
2020.06.13 — 科目二，通过！！！
┌────────────────────────────┐
│  科目二                     │
│  通过！！！                 │
│  └ GAME WORLD · -2 DAYS    │
│     大家第一次看见 PS5。      │
└────────────────────────────┘
```

### 实现

- `narrative.ts` 的 beat 增加 `gameWorld?: { text: string; rel?: string; date?: string }`（人工策展，真实发售日，非数据派生）
- ActSection 渲染脚注行；无该字段则不渲染，零侵入
- 相对时间（-2 DAYS / SAME DAY / +6 DAYS）来自提纲原文，非计算——因为发售日与事件日分属两个坐标系，不强行做差值
