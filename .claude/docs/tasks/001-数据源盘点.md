# 采集任务 #001 · 数据源盘点（可直接粘贴给 DeepSeek）

> 这是全项目的第一个任务。**本任务不收录任何视频条目**，只摸清入口。
> 执行者：数据采集角色（建议 DeepSeek）。产出物：`data/accounts.yaml` + 一份盘点说明。

---

## 任务正文（以下内容整段发给采集 Agent）

你是一个数据采集 Agent，为一个「不搬运资源、只做索引」的存档网站收集**公开可访问**的信息源。

### 目标
盘点中文主播/UP主「女流66」在以下平台的公开账号，以及搬运其直播录播的热心网友账号。**这一轮不要收集具体视频条目。**

平台范围：优酷、哔哩哔哩、YouTube、斗鱼、抖音。

### 产出物 1：`data/accounts.yaml`
YAML 数组，每项字段如下，字段名不得增删：

```yaml
- id: bili-official          # kebab-case，全局唯一
  platform: bilibili         # youku | bilibili | youtube | douyu | douyin
  name: "账号显示名"
  url: "https://space.bilibili.com/xxxxxxx"
  role: official             # official（本人官方号）| mirror（本人小号/分身号）| fan-archive（网友录播搬运号）
  active_from: "2015-06"     # 已知的最早活跃时间，YYYY-MM；不确定就省略这一行
  active_to: "2019-12"       # 已停更则填，仍活跃则省略
  confidence: high           # high | medium | low
  note: "存疑点/补充说明"     # 可省略
```

### 产出物 2：盘点说明（正文回复，不入库）
1. **每个平台一段小结**：找到几个号、哪个是主号、有没有历史更名、有没有已注销的老号。
2. **时间线要点**：各平台大致的起止时间，以及你依据什么材料判断的。
3. **录播生态**：直播期的录播主要由谁在搬？列出你找到的 `fan-archive` 号，按活跃度排序——这决定了后续批量采集的检索入口，是本任务最有价值的部分。
4. **未能确认清单**：你查不到或无法确证的项，逐条列出。**这一项必须写，不许留空。**

### 硬性规则
- **禁止编造。** 任何 URL、ID、日期都必须来自你实际检索到的公开信息。查不到就写"未确认"，不要给一个看起来合理的链接。
- 拿不准的一律 `confidence: low` 并在 `note` 里说明理由。
- 只收录公开账号主页，不收录个人联系方式、住址等任何非公开的个人信息。
- 不确定是不是本人的账号，标 `role: mirror` + `confidence: low`，交人类判断，不要自行认定为 `official`。
- 输出完整的 YAML 文件内容，不要用"省略"「同上」之类的缩写。

### 验收标准
- YAML 可被 `js-yaml` 直接解析
- 每个平台至少有结论（哪怕结论是"未找到公开账号"）
- 「未能确认清单」非空且具体
