## 二、口径与规则

1. 直播时长按「场」计：一天多场各算各的；**同一场直播被不同搬运号拆成多条 entry 时只允许存在一条**，时长以主来源（保留条目）的 duration_min 为准，其余搬运版本全部并入该条 sources。
2. 主条目选择规则：来源数多者优先 → 标题含「时场」者优先 → id 较小者。
3. 判定依据：两条 entry 的 note 互相标注「与 XX 属同场直播的不同录像」且时长吻合（差异 ≤5 分钟）。合并后 note 统一改写为「……为同一场直播的不同搬运版本，总时长吻合，已合并为一天一条（时长以主来源为准）」。
4. 合并时：来源按 URL 去重并入主条目；主条目缺失 tags/games/segments 时从副条目补入；confidence 取高。
