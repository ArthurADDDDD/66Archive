## 二、方法

1. 从 YAML 提取全部 `acfun.cn/v/ac*` 源（含 `parts` 数）
2. 抓取 A站视频页，解析 `window.videoInfo.videoList`（分P标题 + `durationMillis`）
3. `label` = 分P标题去掉 `P{n}-YYYY.M.D-` 前缀，**不做任何推测性改写**
4. `at` = 从 `00:00:00` 起按分P时长累计（floor 到秒），严格递增
5. `game` 仅映射 games.yaml 已登记游戏；未登记一律留空

## 三、segments 形态样例（三种典型）

**单游戏专场**（12-02，5P）：
```yaml
segments:
  - at: "00:00:00"
    label: "恶魔之魂二周目"
  - at: "00:44:59"
    label: "恶魔之魂二周目"
  ...
```

**一场两游戏**（12-18，7P）—— 分P标题体现游戏切换：
```yaml
  - at: "03:02:59"
    label: "赛博朋克2077"
  - at: "03:48:44"
    label: "自由篮球"
    # 02:02:59 起自由篮球 2P（~32min），game 未登记故留空
```

**栏目 + 环节**（12-13 心灵砒霜，5P）—— 直播前聊天环节被正确识别：
```yaml
  - at: "00:00:00"
    label: "砒霜前聊10块钱的弹幕版"
  - at: "00:21:20"
    label: "心灵砒霜弹幕版"
  ...
```
（12-22 的 "游戏前聊10块钱的" 同型，与「一天一场直播=一条 entry」建模原则一致，不另拆条）
