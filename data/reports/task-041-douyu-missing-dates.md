## 2. 57 天的分类

判定规则（重点是**不把后来的标题倒扣到更早那场直播头上**）：

- 抓取时 `show_status=1` → 标题属于当场；
- 缩略图日期＝快照日期（同日）→ 标题属于当场；
- 只有**更晚**的快照：
  - 标题是公告体（请假/回来直播/身体不舒服……）→ **这条公告说的是快照那天，不是更早那场直播**，
    所以那场直播的内容**未知** → `confirmed-date-only`；
  - 标题像内容 → 仍有可能是当场也可能已经换过 → `probable`。

| 类别 | 条数 | 含义 |
|---|---:|---|
| **confirmed-content** | **13 →（复核后）11** | 开播日确定＋标题确属当场，可入库 |
| **probable** | 30 | 标题像内容，但只来自更晚的快照，不足以入库 |
| **confirmed-date-only** | 12 | 确实开播了，但内容不可考（标题是公告体且来自更晚快照） |
| **unusable-title** | 2 | 当场标题本身就是公告（2015-12-06「今天会早点下」、2015-12-17「今天下午4点播」） |

**顺带炸出一个潜伏的前端 bug（已单独修复提交）**：本仓此前 2742 条条目**每一条都至少有一个来源**，
所以「零来源」这条路径从来没被走过。`useEntrySource` 里有一行：

    sourceFallbackCover?.url === selectedSourceUrl ? sourceFallbackCover.cover : null

条目没有任何来源时，`selectedSourceUrl` 是 `undefined`，而 `sourceFallbackCover` 初始为 `null`，
于是 `undefined === undefined` 让这个分支**意外成立**，接着读 `null.cover` 直接抛
`TypeError: Cannot read properties of null (reading 'cover')`。

表现是 `npm run build` 在预渲染 `/games/portal-2` 时整个失败——因为这 11 条里只有
`2015-04-24-live-01` 带了 `games: [portal-2]`，它是唯一会被渲染进游戏页的零来源条目。
已改为先确认 fallback 存在再比对 URL。

## 8. `no_public_replay`：区分「查过确实没有」和「采集时漏填」

```yaml
no_public_replay: true
```

含义是**「这场直播确认发生过，但已经查过，目前找不到任何公开录像」**——
`sources` 为空是**结论**，不是待补的缺口。配套改了三处：

| 位置 | 行为 |
|---|---|
| `scripts/validate.ts` | 标了该字段就不再报「没有任何来源链接」「是直播但缺时长」；同时**新增**一条反向校验：标了却又有来源 → 报矛盾 |
| `scripts/audit/server.mjs` | 审校工具不再把这类条目列为 `high / no-source` |

证据仍然只写在 `note` 里，并**附上存档快照地址**，同时明写

## 13. 关于 Wayback 里那些播放器

人类核对后指出：存档页里的播放器都放不出视频。本轮独立复核，确认如此：

- 「精彩视频」标签页的内容是 AJAX 拉取的，快照里是空的；
- 整页找不到任何 `v.douyu.com/show/...`、`videoId` 之类的可播放地址；
- 直播间缩略图（本可看出在玩什么）**从未被存档**（`archived_snapshots: {}`）。

**所以存档快照只能用来定日期和读标题，不能当录像来源。**
真正可播放的东西只能从 A 站/B 站这类搬运站找——`ac2353769` 就是第一个成功案例。

## 16. 为什么没有把这个号登记进 accounts.yaml

`src/lib/schema.ts` 的 `PLATFORMS` 枚举是
`['youku','bilibili','youtube','douyu','douyin']`——**不含 acfun**。
登记它就得改枚举，而那会牵动平台配色、标签、`detectPlatform()` 等一串展示逻辑，
超出本轮范围。所以这几条 A 站来源和仓里既有的 `ac2434832` 一样**不挂 `account`**，
把号的信息写在来源 note 里。

**这是一个需要人类拍板的口径问题**：仓里已经有 4 条 A 站来源了，
要不要把 acfun 正式纳入平台枚举。
