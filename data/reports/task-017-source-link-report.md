## 一、核查方法

| 平台 | 方法 | 存活判定 |
|------|------|----------|
| B站 (bilibili) | `api.bilibili.com/x/web-interface/view?bvid={BV}` | `code=0` → alive |
| AcFun | `GET /v/ac{id}` 页面抓取 | HTTP 200 + 页面含 `window.videoInfo` → alive |
| 优酷 (youku) | 页面 fetch | HTTP 200 → alive |
