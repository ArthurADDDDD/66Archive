# 系列标签人工复核器

用于复核 `一起See`、`户外`、`聊天` 三个系列标签。它只读取 `data/entries/*.yaml`，不会写入任何正式档案。

```bash
node scripts/series-review/server.mjs
```

打开 <http://127.0.0.1:4174>。逐条勾选最终应保留的系列标签；“确认当前勾选无误”会把该条标为已审。导出的 `series-tag-review.json` 是人工审校计划：交回给维护 Agent 后，仍需先检查 JSON，再依据它生成并复核正式数据 diff。

候选池由两部分组成：当前已带三个标签的条目，以及标题或分段出现发布会、PV、户外、夜话等信号的疑似漏标条目。聊天的机器提示只看标题，避免将“游戏前聊两句”这类分段口语误算为聊天。后者只是待人工确认的提示，绝不自动写入标签。
